# Город-Интернет

> Часть портфолио: [auryxn.codes](https://auryxn.codes) — репозиторий сайта [site-admin](https://github.com/auryxn/site-admin).

> Интерактивная 3D-модель того, как интернет доставляет данные: путь запроса от ввода адреса до отрисовки страницы.

## Что это

Город-Интернет — это обучающая 3D-визуализация, которая показывает, **что на
самом деле происходит**, когда вы вводите адрес сайта в браузере. Абстрактные
сетевые процессы представлены как город: сервисы (роутер, провайдер, DNS,
сервер) — это здания, а данные — грузовики, которые едут по дорогам между ними.

Сценарий состоит из **10 шагов**: кэш, DNS-запрос, обход справочных серверов,
TCP-рукопожатие, TLS, сервер и отрисовка страницы. На каждом шаге по городу
едут «грузовики»-пакеты, камера подлетает к нужному месту, а панель объясняет,
что происходит.

Есть два режима объяснения: **«Просто»** — бытовым языком, и **«Технически»** —
с терминами и командами. Дополнительно можно включить **«Потерять пакет»**
(грузовик теряется на полпути и едет повторно) и **«Зациклить»** (авто-
проигрывание по кругу). Раздел **«Подробнее»** даёт расширенный разбор с
командами диагностики, а **«Квиз»** — 14 вопросов по пройденному материалу.

Подходит для тех, кто учит сети: наглядно видно, что DNS и TCP — это не магия,
а конкретный маршрут и конкретные шаги.

## Возможности

- **Интерактивная 3D-сцена** на Three.js: здания-сервисы, дороги, движущиеся
  машины, небо, тени.
- **10 шагов** от ввода URL до отрисовки страницы, с подсветкой активных узлов.
- **Режимы «Просто» и «Технически»** — два уровня объяснения каждого шага.
- **«Потеря пакета»** — демонстрация потери и повторной отправки.
- **«Зациклить»** и **«Авто»** — автопроигрывание по шагам.
- **Свободная камера** — вращение мышью/свайпом, приближение колесом.
- **«Подробнее»** — расширенный разбор с примерами команд (`dig`, `traceroute`,
  `curl`, `openssl`).
- **Квиз** из 14 вопросов с пояснениями к ответам.
- Навигация по шагам кнопками и стрелками клавиатуры.

## Стек

- **TypeScript** + **Vite**
- **three.js 0.128.0** (закреплена: в новых версиях изменена модель освещения,
  и сцена выглядит темнее)
- Чистый CSS и DOM-интерфейс (без фреймворков)

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # проверка типов (tsc --noEmit) + сборка в dist/
npm run preview  # предпросмотр сборки
```

Проект собран с `base: './'`, поэтому билд из `dist/` можно положить на GitHub
Pages под любым именем репозитория.

## Структура проекта

```
src/
  core/types.ts        типы: узлы, шаги, грузовики, квиз
  data/scenario.ts     граф города (N, E) и сценарий (S) — только данные
  data/content.ts      тексты «Подробнее» (MORE) и вопросы квиза (QZ)
  scene/city.ts        Three.js: здания, дороги, машины, небо, свет, тени
  main.ts              движок шагов, камера, интерфейс, главный цикл
  style.css
index.html             разметка панели управления и canvas
```

Новый сценарий (например, «электронная почта» или «VPN») добавляется как ещё
один массив шагов в `data/` — код сцены при этом не трогается.
